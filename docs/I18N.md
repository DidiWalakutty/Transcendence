# Internationalization

The frontend uses Inlang Paraglide for localization.

## Configuration

The Inlang project is configured in:

```text
apps/frontend/project.inlang/settings.json
```

Current locales:

| Locale | Purpose            |
| ------ | ------------------ |
| `en`   | Base locale.       |
| `nl`   | Dutch translation. |

Message files live in:

```text
apps/frontend/messages
```

## Generated Runtime

Paraglide generates frontend runtime files in:

```text
apps/frontend/src/@generated/paraglide
```

Generated files should not be edited manually.

Run generation with:

```bash
vp run -w repo:frontend:generate
```

or start the frontend through:

```bash
vp run dev
```

The `repo:frontend:generate` task runs Paraglide generation before frontend development, build, checks, tests, and lint tasks that depend on frontend artifacts.

## Locale Switching

The navigation locale switcher lives in:

```text
apps/frontend/src/components/navigation/LanguageSwitcher.tsx
```

It localizes the current canonical route with Paraglide, replaces the public URL
through TanStack Router's history adapter, and invalidates the route tree. This
updates translations and the document language in place after hydration without
a full document reload. Direct URL visits and refreshes remain server-rendered.

## Localized Routing

Application routes are canonical and locale-neutral. Route files and TanStack
Router links use paths such as `/events`, `/admin`, and
`/events/$eventId`; they do not declare or pass a `locale` route parameter.

The router rewrite configured in `apps/frontend/src/router.tsx` delegates both
directions to Paraglide:

- incoming localized URLs are converted to canonical routes before matching;
- outgoing links and navigations are localized automatically.

The URL strategy uses English as the unprefixed base locale and prefixes Dutch:

| Canonical route | English URL | Dutch URL    |
| --------------- | ----------- | ------------ |
| `/`             | `/`         | `/nl/`       |
| `/events`       | `/events`   | `/nl/events` |
| `/admin`        | `/admin`    | `/nl/admin`  |

`apps/frontend/src/server.ts` wraps the TanStack Start handler with Paraglide
middleware so locale detection is also available during server rendering.
