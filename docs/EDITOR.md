# Editor

The project standard editor is Visual Studio Code.

VS Code is used because the planned devcontainer can install and configure the recommended extensions consistently for every contributor.

## Expectations

- Use the workspace settings and recommended extensions when available.
- Keep formatting and linting delegated to Vite+ tasks and commit hooks.
- Do not rely on editor-only behavior that cannot be reproduced by `vp run check`.

For extension details, see [Extensions](./EXTENSIONS.md).
