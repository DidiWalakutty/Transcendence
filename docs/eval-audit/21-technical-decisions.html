What the code shows

Answers the code supports

QuestionAnswer
Why tRPC instead of REST?End-to-end types: the frontend imports the backend's procedure types, so a renamed field fails tsc instead of failing at runtime. Same Zod schema validates both sides. Cost: not a public REST API (which is why the "Secure Public API" module is not claimed).
Why NestJS?Modules + dependency injection let nine features live side by side with the same shape (router/service/repository) and be unit-tested with in-memory repositories.
Why TanStack Start over Next.js?SSR + file routing on plain React and Vite, type-safe search params (used for filters/pagination URLs), and it fits tRPC + TanStack Query natively.
Why Drizzle over Prisma?SQL-shaped queries, tables defined in TypeScript, migrations generated from the schema, and drizzle-zod gives validation schemas from the same definition.
Why PostgreSQL + Redis?Relational data with real constraints (FKs, partial unique index on registrations); Redis for the cache and rate-limit counters so several backend instances would share them.
Why SSE not WebSockets?See Q18.
Why better-auth?Sessions, scrypt hashing, 2FA, admin/username plugins, OAuth-ready, all on our own Postgres tables via the Drizzle adapter — instead of writing crypto ourselves.
Why Caddy?Two-line TLS termination and routing; HTTP→HTTPS redirect; rootless-Docker ports.
Why Bun + Vite+?One toolchain for install/run/test/format/lint across the monorepo; task graph in vite.config.ts keeps generated code in sync.
Images as data URLs?Trade-off: no object storage to run; client compresses to ≤72 kB; rows are bigger. Would move to S3-style storage for production.

War stories that are already in the repo (use them)

  • Mixed-content: the first HTTPS attempt had the browser calling http://localhost:3001 → moved everything behind Caddy with relative URLs (api-base-url.ts).
  • Firefox aborting requests on navigation and logging TypeErrors → BS-11 in BROWSER_SUPPORT.md.
  • The PWA service worker failing on the self-signed cert on every page → removed (BS-1).
