How to print

Open a lesson in a browser and press Ctrl+P, or use its Print / save as PDF button. Choose a printer or Save as PDF. A4 portrait is configured, and the layout also wraps for other paper sizes. Turn off browser headers and footers if you do not want the file URL on each page. Background graphics are optional; the pages remain readable in black and white.

Answers and source code start on new pages, so you can print the explanation first and choose later pages separately in the print dialog. There are no external fonts, scripts or images required to read the lessons. Repository links need the rest of the checkout.

These notes explain the actual inspected implementation, including limitations visible in the code. They do not silently fix application behavior or treat every source comment as a verified guarantee.
